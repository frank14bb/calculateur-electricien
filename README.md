# Calculateur Électricien

Outil de référence rapide, en une seule page web (`index.html`), pour usage personnel sur le chantier. Fonctionne hors ligne une fois la page ouverte dans un navigateur — aucune installation requise.

## Fonctions

- **Chute de tension** — calcule la chute de tension (V et %) selon le calibre, la longueur, le courant et le type de circuit (monophasé/triphasé), en cuivre ou aluminium.
- **Remplissage de boîte** — calcule le volume requis (po³) selon le nombre de conducteurs, appareils, serre-câble et support de luminaire, et le compare au volume disponible.
- **Calibre de fil** — suggère le calibre minimum selon la charge à alimenter et la colonne de température (60/75/90 °C).
- **Remplissage de tuyau** — calcule le pourcentage de remplissage d'un conduit (EMT, PVC, rigide métallique) selon les conducteurs qu'il contient.

## Important

Cet outil est une référence rapide et ne remplace pas le Code de construction (Chapitre V, Électricité) ni le livre bleu d'Hydro-Québec. Toujours confirmer les valeurs avec les tableaux officiels avant de fermer un travail.

## Utilisation

Ouvrir `index.html` dans n'importe quel navigateur.
